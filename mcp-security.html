What we test

Tested by hand, end to end

A focused, manual engagement across the full mcp attack surface.

Tool poisoning

Malicious or manipulated tool descriptions that hijack model behavior.

Server authorization

Missing or broken auth on MCP servers exposing tools and data.

Prompt-relay abuse

Untrusted content reaching the model through tool outputs.

Data scope

Tools over-exposing data or actions beyond their intent.

Unsafe actions

Tools that perform privileged or destructive operations without guardrails.

Supply chain

Third-party MCP servers and their trust assumptions.

Coverage

Mapped to the OWASP LLM Top 10 (2025)

MCP is part of the LLM tool ecosystem, so findings are mapped to the OWASP Top 10 for LLM Applications, the industry-standard AI framework.

LLM01

Prompt Injection

Direct and indirect instructions that override behavior.

LLM02

Sensitive Information Disclosure

Leakage of secrets, PII or proprietary data.

LLM03

Supply Chain

Risks from third-party models, tools and MCP servers.

LLM04

Data & Model Poisoning

Tampering with training, tuning or embedding data.

LLM05

Improper Output Handling

Unsafe downstream use of model and tool output.

LLM06

Excessive Agency

Tools and agents with too much permission.

LLM07

System Prompt Leakage

Exposure of system prompts, logic and secrets.

LLM08

Vector & Embedding Weaknesses

Attacks against RAG, embeddings and vector stores.

LLM09

Misinformation

Confident, incorrect or fabricated output.

LLM10

Unbounded Consumption

Resource and cost abuse via expensive operations.
