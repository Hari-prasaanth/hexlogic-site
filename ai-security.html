Coverage

Mapped to the OWASP LLM Top 10

Every finding is categorized against the industry-standard framework, so your risk is legible to engineering, security and leadership alike.

LLM01

Prompt Injection

Direct and indirect instructions that override intended behavior, including payloads hidden in retrieved content.

LLM02

Sensitive Information Disclosure

Leakage of PII, secrets or proprietary data through model outputs.

LLM03

Supply Chain

Risks from third-party models, datasets, plugins and MCP servers.

LLM04

Data & Model Poisoning

Tampering with training, fine-tuning or embedding data to bias or backdoor the model.

LLM05

Improper Output Handling

Unsafe use of model output downstream — XSS, SSRF, code execution.

LLM06

Excessive Agency

Agents with too much permission performing unverified or destructive actions.

LLM07

System Prompt Leakage

Exposure of system prompts revealing logic, credentials or guardrails.

LLM08

Vector & Embedding Weaknesses

Attacks against RAG pipelines, embeddings and vector stores.

LLM09

Misinformation

Confident, incorrect or fabricated output relied on for decisions.

LLM10

Unbounded Consumption

Resource and cost abuse through unthrottled or expensive operations.

What we test

Testing the tools your model can reach

Model Context Protocol turns an LLM into an actor in your systems. We test that new trust boundary directly.

Tool poisoning

Manipulated tool descriptions that silently hijack agent behavior.

Server authorization

Auth and scoping on MCP servers exposing tools, files and actions.

Unsafe actions

Privileged or destructive tool calls performed without guardrails.

Prompt-relay abuse

Untrusted tool output that smuggles instructions back to the model.
